# Fundamentos de Desarrollo Web para Principiantes

## Resumen del Curso

Este curso está diseñado para estudiantes de secundaria interesados en aprender a crear sitios web básicos utilizando **HTML** y **CSS**. A lo largo de una serie de lecciones prácticas y fáciles de seguir, los participantes aprenderán a estructurar contenido con HTML y a darle estilo mediante CSS, todo sin necesidad de instalar software adicional. **¡Solo necesitas tu navegador web!**


*Duración total*: ~150 minutos  
*Público Objetivo*: Estudiantes de 12 a 17 años sin experiencia en programación  
*Prerrequisitos*: Ninguno  
*Herramientas necesarias: *¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)  
*📂 Repositorio de Código Fuente*: [https://github.com/Los-Bytes/webdev-course-Los-Bytes](https://github.com/Los-Bytes/webdev-course-Los-Bytes)

## Secuencia de la Lección

### Lección 1: ¿Qué es el desarrollo web? (5 minutos)
- *Descripción*: Aprende de qué están hechos los sitios web y por qué **HTML* y *CSS* son los componentes básicos.
- *Enlace*: [Ver la lección](https://youtu.be/50tiEX9dDc4)
- *Consejos clave*: Un sitio web se construye con HTML para organizar el contenido (como texto e imágenes) y CSS para darle estilo (como colores y disposición). Piensa en HTML como el esqueleto de la página y en CSS como la ropa que la hace atractiva. Ambos son fundamentales para crear una página web funcional y visualmente atractiva.
- *Empieza a programar*: [Open CodePen](https://codepen.io/your-work)

### Lección 2: Introducción a HTML (20 minutos)
- *Descripción*: Explora las etiquetas HTML básicas y crea tu primera página.
- *Enlace*: [Ver la lección](https://youtu.be/Auj0sgslVYY)
- *Consejos clave*: En esta lección, aprenderás las etiquetas básicas de HTML. La etiqueta "html" define el inicio de un documento HTML, "head" contiene información sobre la página (como el título), y "body" es donde va el contenido visible. Usa "h1" para los encabezados principales y "p" para los párrafos. Estas etiquetas son la base para crear tu primera página web. ¡Escribe y experimenta con ellas para ver cómo estructurar el contenido!
- *Práctica*: [Clic para programar](https://codepen.io/Joel-el-fail/pen/jEqrwXV)

### Lección 3: Añadir más elementos HTML (19 minutos)
- *Descripción*: Agrega listas, imágenes y enlaces para que tu página sea interactiva.
- *Enlace*: [Ver la lección](https://youtu.be/svutlPD4RmU)
- *Consejos clave*: En esta lección, aprenderás a agregar más elementos interactivos a tu página. Usa "ul" para crear listas sin orden y "li" para cada elemento dentro de la lista. Para añadir imágenes, utiliza la etiqueta "img" y no olvides el atributo src para indicar la fuente de la imagen. Los enlaces se crean con la etiqueta "a" y el atributo href para especificar la URL de destino. Estos elementos harán que tu página sea más dinámica y atractiva.
- *Práctica*: [Clic para programar](https://codepen.io/Joel-el-fail/pen/OPNXgGV)

### Lección 4: Introducción a CSS (33 minutos)
- *Descripción*: Dale estilo a tu HTML con colores, fuentes y diseños.
- *Enlace*: [Ver la lección](https://youtu.be/P9TAqm5jlRg)
- *Consejos clave*: En esta lección, aprenderás a darle estilo a tu página web con CSS. Para vincular CSS a tu HTML, puedes usar la etiqueta "style" en el "head" o un archivo externo con "link". Utiliza selectores como body para aplicar estilos generales (por ejemplo, "background - color" para cambiar el color de fondo). Además, puedes modificar propiedades como el color de texto, el tamaño de la fuente y el espaciado. CSS es clave para hacer que tu página se vea atractiva y bien organizada.
- *Práctica*: [Aplicar estilo con un clic](https://codepen.io/Joel-el-fail/pen/JoXKJVm)

### Lección 5: Crear una página web sencilla (30 minutos)
- *Descripción: Combina **HTML* y *CSS* para crear una página de perfil personal.
- *Enlace*: [Ver la lección](https://youtu.be/UzRBsvQVC44)
- *Consejos clave*: En esta lección, combinarás HTML y CSS para crear una página de perfil personal. Usa HTML para estructurar el contenido (como tu nombre, foto y biografía) y CSS para darle estilo (como colores, márgenes y tipografía). Asegúrate de depurar cualquier error, revisando que las etiquetas estén bien cerradas y los estilos aplicados correctamente. Este proyecto es una excelente manera de practicar lo aprendido y crear una página web funcional y estilizada.
- *Proyecto Final*: [Crea tu Perfil](https://codepen.io/Joel-el-fail/pen/wBGWebG)

### Lección 6: Proyecto Final Guiado – Página Web Completa  (41 minutos)
- *Descripción*: Guiar a los estudiantes a crear una página web avanzada con una barra de navegación, contenido organizado y diseño responsivo. El proyecto incluirá efectos interactivos y una estructura más compleja.
- *Enlace*: [Ver la lección](https://youtu.be/gMxYPspspOo)
- *Consejos clave*: En esta lección final, los estudiantes crearán una página web avanzada que incluya una barra de navegación, contenido organizado y diseño estetico. Asegúrate de depurar cualquier error en el código, como etiquetas mal cerradas o estilos no aplicados correctamente. Además, es importante que exploren la documentación de CSS para entender cómo hacer que la página se adapte a diferentes tamaños de pantalla. Utiliza efectos interactivos como el hover en los enlaces para hacer que la navegación sea más atractiva. ¡Este proyecto es la oportunidad de aplicar todo lo aprendido para crear una página web profesional!
- *Práctica*: [Haz clic para practicar](https://codepen.io/Joel-el-fail/pen/VYajWON)
- *Compartir tu trabajo*: [Codigo completo](https://codepen.io/Joel-el-fail/pen/OPNMOMP)
